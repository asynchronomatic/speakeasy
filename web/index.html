Welcome

Point Open WebUI and other OpenAI-compatible apps at this proxy

OpenAI endpoint

This proxy speaks the OpenAI HTTP API. Use the base URL below as the API endpoint in any compatible client.

No API key is required. If a client refuses an empty key, use any placeholder such as sk-speakeasy.

You are viewing this dashboard on localhost. Apps on other machines — or Open WebUI in Docker — cannot reach 127.0.0.1. Use this computer’s LAN address, or host.docker.internal from Docker Desktop.

Open WebUI

  1. Open Admin Settings → Connections (or user Settings → Connections).
  2. Enable the OpenAI API connection.
  3. Set API Base URL to the OpenAI endpoint above (it must end in /v1).
  4. Set API Key to any value, then save.
  5. Mesh models show up in the Open WebUI model picker.
